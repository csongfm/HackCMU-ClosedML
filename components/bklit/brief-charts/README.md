# Bklit chart primitives

Source: https://ui.bklit.com/r/{name}.json (bar-chart, line-chart, area-chart, pie-chart and their registry dependencies), retrieved September 12, 2026. MIT license: licenses/Bklit-UI.txt from the repository root.

Components are isolated here to preserve the existing location map. Local adaptation: chart-loading-label imports the colocated shimmering-text component. Unused registry files were omitted. Brief-specific composition, data validation, styling and accessibility live in components/briefly and lib/interactive-brief.ts.
